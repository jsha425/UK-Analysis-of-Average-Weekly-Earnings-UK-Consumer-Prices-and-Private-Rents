# Have-Earnings-Kept-Pace-with-Rising-Prices-in-the-UK
**Objective:** This project examines whether CPIH growth and Private Rent increases have displaced income growth through using CPIH inflation, average weekly earnings data and private rent indices  between 2015 and 2025. Data was all indexed with 2015 = 100, the base year to allow for comparison across categories, nominal income was also deflated using the CPIH indexes to find real income and create an exact amount of growth comparable to inflation.

**Data:** 
ONS CPIH
ONS Average Weekly Earnings — Total Pay
ONS Price Index of Private Rents
2015–2025
Monthly data was aggregated to annual averages and CPIH and private rent data covered the UK whilst the earnings series covers Great Britain

**Method:**
Collated monthly ONS data
|
Cleaned using pandas in python
|
Created annual avergaes
|
Made 2015 as base index of 100
|
Calculated growth calculations
|
CPIH deflated earnings
|
Merged data sets
|
Used Matplotlib to provide visualisation

**Results:**
CPIH:                  +38.0%
Average earnings:      +50.9%
Private rents:         +45.4%
Real earnings index:   +9.35%
Deterioration occurred of real earnings in 2022

**Limitations:**
  - Average weekly earnings was Great Britain rather than UK
  - Private rent growth has variations dependant on household size, location, property type
